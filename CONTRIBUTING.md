# Contributing to brasilguard-v2 — BRafaelS open-source candidate

> **PREPARATION ONLY — this repository is not declared MIT-licensed by this file.**

Before filing contributions, confirm that you have the necessary rights to submit your original work and that it does not contain third-party confidential information or credentials. Any contribution must preserve attribution and applicable upstream licenses. Contributions may be considered for acceptance only after the maintainers define the final code-license scope and contributor terms.

## Security
Do not disclose active credentials, personal data or exploit details in public issues. Use the repository's private security-reporting channel if configured or contact the maintainers through an authenticated private channel. A public issue is not an authorization to publish vulnerabilities.

## Brand
**BRafaelS** is a reserved commercial brand, capital B, R and S. Software licensing does not automatically license names, logos, endorsements or trade dress.

## Release gate
Publication, pull-request merge, and any MIT release must follow author attribution, dependency provenance, privacy, tests and human approval for the exact release snapshot.
